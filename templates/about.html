About

SecretGen is a free, public API that generates cryptographically random secrets — no auth, no rate limits, no nonsense.

Usage

  • GET /32 — a 32-character secret
  • GET /64 — a 64-character secret
  • GET /128 — a 128-character secret

Secrets are generated using Node's crypto.randomBytes.

Who's behind this

Built & Maintained by StuxAPIs, Hosted by Stuxedo. The source is fully open on GitHub.
