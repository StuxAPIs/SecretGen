Accuracy

This is a secret-generation API - there's no factual content to be accurate or inaccurate about. Uptime is best-effort, not guaranteed.

Fitness for use

Secrets are generated using Node's crypto.randomBytes. While this is a cryptographically secure source of randomness, you're responsible for deciding whether this service is appropriate for your specific security needs.

Security
